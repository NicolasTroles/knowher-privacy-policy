1. Edite o `.md` correspondente.
2. Commit + push.
3. GitHub Pages atualiza automaticamente em ~1min.

## Stack

HTML/CSS puros + [marked.js](https://marked.js.org/) via CDN pra renderizar o markdown no client. Sem build.
